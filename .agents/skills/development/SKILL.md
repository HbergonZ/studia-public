# Skill de Desenvolvimento

## Objetivo

Implementar código de produção de forma segura, simples e consistente.

---

## Processo

1. Ler as instruções do projeto.
2. Entender a funcionalidade.
3. Inspecionar código relacionado.
4. Identificar pontos de alteração.
5. Planejar a implementação.
6. Implementar.
7. Executar testes.
8. Revisar as alterações.

---

## Regras

Não:

- reescrever código sem necessidade;
- alterar arquitetura sem justificativa;
- adicionar dependências desnecessariamente;
- modificar funcionalidades não relacionadas;
- copiar diretamente código de protótipos sem revisão.

---

## Antes de implementar

Identificar:

- arquivos envolvidos;
- componentes relacionados;
- regras de negócio;
- dependências;
- testes existentes.

---

## Depois de implementar

Verificar:

- funcionamento;
- tratamento de erros;
- casos extremos;
- testes;
- impacto em funcionalidades existentes;
- alterações inesperadas.
